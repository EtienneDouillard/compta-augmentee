name: grill-with-docs
description: A relentless interview to sharpen a plan or design, which also creates docs (ADRs and glossary) as we go. Use when the user types /grill-with-docs or asks to "grill" a plan in this repo.
---

Run two skills together for this whole session:

1. **grilling** — interview the user in numbered rounds with a recommended answer for each question, until the design tree's frontier is empty.
2. **domain-modeling** — while grilling, challenge and sharpen terms, write each resolved term to `GLOSSARY.md` immediately, and offer an ADR in `docs/adr/` only for decisions that are hard to reverse, surprising, and a real trade-off.

If either skill body is not already in context, read it from the workspace skills before starting. Do not build anything until the user confirms shared understanding.
